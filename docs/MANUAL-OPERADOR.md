# StageMaster · Manual del operador

Guía rápida para quien lleva el marcador desde el iPhone.

---

## Antes del partido

1. **iPhone**:
   - *Ajustes → Pantalla y brillo → Bloqueo automático → Nunca*.
   - **Modo avión + Wi-Fi activado**, conectado a la red del evento.
   - Batería > 80 % o cargador conectado. Modo de bajo consumo **desactivado**.
2. Abre **StageMaster** desde el icono de la pantalla de inicio.
   La primera vez: Safari → dirección que te den (ej. `http://192.168.0.121:3000`)
   → *Compartir → Añadir a pantalla de inicio*.
3. Comprueba abajo del panel: **● Conectado** en verde.

## Configurar el partido

| Campo | Qué elegir |
|---|---|
| Nombres | Pareja A y pareja B (máx. 30 caracteres, ej. `Galán / Lebrón`) |
| Games por set | Normalmente **6** |
| Cantidad de sets | **3** (al mejor de 3) |
| Sistema de puntuación | **Ventaja**, **Punto de Oro** o **Punto Estrella** (según el torneo) |
| Desempate | **Tie Break** (a 7), **Super TB** (súper tie break a 10 en lugar del 3.er set) o **Ninguno** |
| Saque inicial | La pareja que saca primero |

Pulsa **INICIAR PARTIDO**. La pantalla LED muestra los nombres al instante.

## Durante el partido

| Botón | Cuándo |
|---|---|
| **PUNTO A / PUNTO B** | Al terminar cada punto, para la pareja que lo ganó |
| **DESHACER ÚLTIMA ACCIÓN** | Si te equivocas. Toca **dos veces** (la primera pide confirmación) |
| **CAMBIAR SAQUE** | Solo si la pelota 🎾 no coincide con quien saca de verdad |
| **Reiniciar** | Pone el marcador a 0-0 (pide confirmación) |
| **Finalizar** | Termina el partido con el marcador actual (pide confirmación) |

El sistema cuenta solo: games, sets, tie break, súper tie break, cambio de saque y ganador.

**Avisos que puedes ver:**
- **PUNTO DE ORO / PUNTO ESTRELLA**: el siguiente punto decide el game.
- **TIE BREAK / SUPER TB**: los puntos cuentan 1, 2, 3…
- **"El marcador cambió desde otro dispositivo"**: otro teléfono sumó un punto;
  revisa el marcador antes de volver a pulsar.

## Si algo va mal

| Lo que ves | Qué hacer |
|---|---|
| Barra **roja "Desconectado · Reconectando…"** | Espera unos segundos sin pulsar: se reconecta solo con el marcador correcto. Los toques sin conexión **no** cuentan. |
| Sumaste el punto al equipo equivocado | **Deshacer** (dos toques) y suma el correcto |
| Pulsaste **Finalizar** por error | En la pantalla final: **Volver al marcador → Deshacer** |
| Tocaste dos veces seguidas sin querer | No pasa nada: el sistema solo cuenta un toque |
| El iPhone se apagó o se quedó sin batería | Usa el teléfono de respaldo con la misma dirección: entra directo al partido |
| "Partido en curso… ¿Quieres reemplazarlo?" | Pulsa **Cancelar** salvo que quieras borrar el partido actual |

## Al terminar

La pantalla LED muestra ⭐ junto al ganador. En el iPhone pulsa **Nuevo partido**
para configurar el siguiente: la LED mantiene el resultado final hasta que lo inicies.
